# 🔍 ObjDetect

Um script Python rápido e fácil de usar para detecção de objetos, utilizando o módulo DNN do OpenCV e o modelo SSD MobileNet pré-treinado no conjunto de dados COCO.

![ObjDetectDemo](https://github.com/KrishBharadwaj5678/ObjDetect/raw/main/ObjDetectDemo.png)

## ✨ Funcionalidades

| Funcionalidade                                  | Descrição                                           |
| ----------------------------------------------- | --------------------------------------------------- |
| 🏷️ Detecta 80 classes comuns de objetos (COCO) | Reconhecimento de objetos no conjunto de dados COCO |
| 🐍 Script Python simples                        | Implementação fácil usando OpenCV                   |
| 🎥 Extensível para vídeo e câmera em tempo real | Suporte para entrada de vídeo ao vivo               |
| 🧠 Modelo pré-treinado                          | Utiliza modelo de deep learning já treinado         |
| 🖼️ Suporte para imagens de alta resolução      | Funciona com imagens de alta qualidade              |
| ⚡ SSD MobileNet leve                            | Arquitetura otimizada para desempenho em tempo real |

---

## 🧰 Tecnologias Utilizadas

| Tecnologia           | Descrição                                               |
| -------------------- | ------------------------------------------------------- |
| 🐍 **Python**        | Linguagem principal para lógica e scripts               |
| 🧠 **OpenCV**        | Processamento de imagens e carregamento do modelo DNN   |
| 🤖 **SSD MobileNet** | Modelo leve de detecção de objetos pré-treinado no COCO |
| 🗂️ **COCO Dataset** | Conjunto de dados com 80 classes de objetos             |
