# 🔍 ObjDetect

Быстрый и простой Python-скрипт для обнаружения объектов с использованием модуля DNN в OpenCV и модели SSD MobileNet, предварительно обученной на наборе данных COCO.

![ObjDetectDemo](https://github.com/KrishBharadwaj5678/ObjDetect/raw/main/ObjDetectDemo.png)

## ✨ Возможности

| Функция                                       | Описание                                       |
| --------------------------------------------- | ---------------------------------------------- |
| 🏷️ Определение 80 классов объектов (COCO)    | Распознавание объектов из набора COCO          |
| 🐍 Простой Python-скрипт                      | Лёгкая реализация с использованием OpenCV      |
| 🎥 Расширяемость для видео и камеры           | Поддержка обработки видео и потокового ввода   |
| 🧠 Предобученная модель                       | Используется готовая модель глубокого обучения |
| 🖼️ Поддержка изображений высокого разрешения | Работа с качественными изображениями           |
| ⚡ Лёгкая архитектура SSD MobileNet            | Оптимизирована для работы в реальном времени   |
