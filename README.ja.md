# 🔍 ObjDetect

OpenCVのDNNモジュールと、COCOデータセットで事前学習されたSSD MobileNetモデルを使用した、高速で使いやすいPythonの物体検出スクリプトです。

![ObjDetectDemo](https://github.com/KrishBharadwaj5678/ObjDetect/raw/main/ObjDetectDemo.png)

## ✨ 機能

| 機能                  | 説明                   |
| ------------------- | -------------------- |
| 🏷️ 80種類の一般的な物体を検出  | COCOデータセットの物体クラスに対応  |
| 🐍 シンプルなPythonスクリプト | OpenCVを使用した簡単な実装     |
| 🎥 動画・リアルタイム拡張可能    | カメラ入力や動画にも対応可能       |
| 🧠 事前学習済みモデル使用      | 学習済みのディープラーニングモデルを使用 |
| 🖼️ 高解像度画像対応        | 高品質な画像入力をサポート        |
| ⚡ 軽量SSD MobileNet   | リアルタイム処理に適した高速モデル    |

---

## 🧰 技術スタック

| 技術                   | 説明                  |
| -------------------- | ------------------- |
| 🐍 **Python**        | スクリプトとロジックの主要言語     |
| 🧠 **OpenCV**        | 画像処理およびDNNモデルの読み込み  |
| 🤖 **SSD MobileNet** | COCOで学習済みの軽量物体検出モデル |
| 🗂️ **COCOデータセット**   | 80種類の物体クラスを持つデータセット |
